## 发布动作

在把仓库设为公开之前，逐项完成以下任一处理：

1. 获得版权所有者允许在 GitHub 与演示页面传播的书面授权；或
2. 用自己拍摄且有权公开的照片替换；或
3. 使用许可证明确允许再发布的素材，并把许可证和署名写入本文件；或
4. 不提交图片二进制文件，只保留素材清单和替换说明。

校徽、官方标准字及学校品牌资产目前**没有**被复制进个人版；若后续使用，也需要单独确认校方视觉规范与公开使用范围。
