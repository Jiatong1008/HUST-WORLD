# Test report retention

- `test-matrix-quick.json` is intentionally ignored: it is regenerated by frequent local checks and should not create Git noise.
- `test-matrix-standard.json` and `test-matrix-full.json` remain versioned as evidence for broader regression runs.

Use `npm run test:quick`, `npm run test:standard`, or `npm run test:full` to regenerate the corresponding report locally.
