# HUST WORLD Personal Edition

这个仓库是基于小组课程设计 **HUST WORLD** 建立的个人延续版本。它保留了原项目的完整运行基础，并在此基础上由 **Jiatong**（GitHub：[Jiatong1008](https://github.com/Jiatong1008)）维护和扩展产品设计、叙事闭环、素材治理、测试与部署文档。

## 本人新增范围

- 叙事垂直切片「喻园第一周」：报到 → 图书馆学习 → 醉晚亭夜游 → 帮助下一位新同学。
- 独立叙事存档、记忆卡、三维倾向统计与多结局。
- 以真实校园场景为参考的图片/建筑线稿接入，并附素材来源登记。
- 对应的浏览器自动化测试，以及个人发布前检查清单。

## 对外署名原则

- 不将原小组共同完成的代码、设计或资源表述为个人从零独立开发。
- GitHub 仓库简介和简历可写：`基于团队课程设计持续个人迭代，负责个人版的叙事系统、产品化、测试与部署。`
- `package.json` 已标注个人维护者 Jiatong；请在仓库首页保留本文件链接。

## 建议的 GitHub 仓库结构

```
main                 # 稳定演示版本
feature/campus-week  # 后续功能分支示例
docs/personal/       # 个人工作边界、设计与发布说明
docs/ASSET_ATTRIBUTION.md
```

首次上传前，先检查 [素材登记](../ASSET_ATTRIBUTION.md) 中的授权状态；没有取得公开传播授权的素材，应改为自行拍摄、明确可商用素材，或不提交到公开仓库。
