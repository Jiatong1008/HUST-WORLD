# HUST 校园特色元素填充说明

## 范围

本次填充覆盖 HUST WORLD 的华科校园特色元素，包括：地图 POI、NPC 对话与梗、任务、物品、校园巴士、成就共 6 类。

## 各元素落在哪个系统

| 元素类型 | 所在文件/系统 | 说明 |
|----------|---------------|------|
| POI 地点 | `map/mapdata/map_locations.json` | 教学楼、宿舍、食堂、地标、操场、巴士站等 48 个地点 |
| NPC 对话 | `game/js/config/DialogueConfig.js` + `game/js/config/NpcConfig.js` | 迎新志愿者、教官、高数老师、图书馆管理员、社团负责人、跑步教练、食堂阿姨、实验室导师、实习学长、毕设导师、答辩老师、超市老板 |
| 任务 | `game/js/config/QuestTriggerConfig.js` | 主线 10 条 + 支线 8 条，按年级学期推进 |
| 物品 | `game/js/config/ItemConfig.js` | 消耗品、任务物品、收藏品、武汉特色食物、校园卡/实验室通行证等 |
| 校园巴士 | `map/js/config.js` + `map/js/BusTravel.js` | 巴士站 8 个，路线 3 条（环线/东西线/南北线），票价 1 元 |
| 成就 | `game/js/config/AchievementConfig.js` + `game/js/ui/GameDashboardUI.js` 成就面板 | 15 项成就，任务奖励自动解锁，面板展示已解锁/未解锁状态 |

## 为什么加

1. 让游戏场景与华中科技大学真实校园产生强关联，增强代入感。
2. 为任务链提供具体地标和触发点，让“大学四年”主循环有据可依。
3. 通过 NPC 对话和校园梗（四大名补、森林大学、占座、光马、热干面等）强化文化记忆点。
4. 物品、巴士、成就系统丰富成长反馈，支撑角色培养与探索循环。
